# 아스테르 SVG 지도 단축어 — 통합 기숙사 v6

새 지도 `https://5aaa.uk/m/202612.webp`를 반영한 수정본입니다.

## 적용

1. ZIP의 배포 파일을 기존 GitHub 저장소 최상위에 덮어씁니다.
2. 기존 Cloudflare 연동으로 재배포합니다. 빌드 명령은 `npm run check`, 배포 명령은 `npm run deploy`입니다.
3. 단축어를 `단축어_템플릿.txt` 내용으로 교체합니다.

Worker 이름은 `map`, 주소는 `https://map.a202214421.workers.dev`입니다. `worker.mjs`뿐 아니라 `map-svg.mjs`도 반드시 교체해야 새 지도가 적용됩니다. 이 패키지를 만든 것만으로 운영 Worker가 재배포되지는 않습니다.

## 변경 사항

- 배경을 202612 지도 이미지로 교체했습니다. 원본을 축소한 JPEG를 SVG에 내장하므로 실행 시 원본 이미지 서버에 의존하지 않습니다.
- 기숙사 표기와 좌표를 남쪽 한 건물로 통합했습니다. 새 입력은 코드 15를 사용합니다.
- 옛 코드 16도 자동으로 15로 변환합니다. 17~22를 포함한 나머지 코드 번호는 유지합니다.
- 무작위 위치 배정의 성별 구분을 제거했습니다. 교수는 기존처럼 기숙사 무작위 후보에서 제외합니다.
- 새 지도에서 보이는 본관·도서관·훈련장·던전 입구·식당·의무실·호수·정문 위치에 핀을 맞췄습니다. 실내 시설은 소속 건물, 던전 각 층은 입구에 표시합니다.
- 루엔은 정문에서 이어지는 지도 밖 표식입니다. 실제 시내 지리를 나타내지는 않습니다.
- 양피지 번호·명단, 상하단 설명 없는 디자인, 3장·장당 5명 구성을 유지합니다.
- 캐시 버전은 `parchment-unified-dorm-v6`, 단축어 URL은 `v=6`입니다.

## 위치를 모르는 경우

확인한 현재 위치를 우선 사용합니다. 불명인 경우 단축어를 수행하는 AI가 시간표·신분에 맞는 장소를 배정한 뒤 계승합니다. Worker 자체는 RP 시간표를 받거나 저장하지 않습니다.

0·빈 값·잘못된 코드가 들어오면 Worker가 무작위 후보 중 배정합니다. 던전·금서고·의무실·사망은 무작위 후보에 넣지 않습니다. 명시적으로 전달된 유효 위치와 사망 코드는 유지합니다.

## 출력 경로

- `/1.png`, `/2.png`, `/3.png`: 채팅에 넣는 PNG 이미지.
- `/1`, `/2`, `/3`: 같은 PNG 출력.
- `/1.svg`, `/2.svg`, `/3.svg`: 원본 SVG.
- `p`는 해당 장의 인물 순서대로 위치 코드 5개를 쉼표로 구분합니다.

재배포 후 확인 예시:

`https://map.a202214421.workers.dev/1.png?v=6&p=15,16,15,8,13`

첫 세 인물이 동일한 기숙사에 표시되어야 합니다. 16은 하위 호환 확인을 위해 넣은 값입니다.

한글은 글자 도형으로 변환합니다. PNG 변환은 기존과 동일하게 외부 이미지 서비스 wsrv.nl을 사용하므로 해당 서비스 장애 시 PNG 변환이 실패할 수 있습니다. 외부 변환 URL에는 고정 인물 페이지·숫자 위치 코드·버전만 들어갑니다.

## 파일

- `worker.mjs`: PNG/SVG 요청과 PNG 변환 중계.
- `map-svg.mjs`: 새 배경과 위치·핀·명단 렌더링.
- `text-paths.mjs`, `glyphs.mjs`: 한글 글자 도형.
- `wrangler.jsonc`, `package.json`, `package-lock.json`: 기존 배포 설정.
- `FONT-LICENSE.txt`: Noto Sans CJK KR 라이선스.
- `단축어_템플릿.txt`: 복사할 단축어.

로컬 검증과 원격 배포 여부는 `검증결과.txt`를 참고하세요.
